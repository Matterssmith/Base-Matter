# Internationalization lookup

`Translator` holds a selected locale and translation catalogs in memory. A
catalog is registered as a map of string keys to string values. `translate`
returns the translated value for the active locale; when no value is present,
it returns the key itself. `contains` checks a specific locale and key.

`Translator::default()` selects `es`, but the crate does not bundle catalogs,
validate locale tags, load files, or provide a fallback chain. Callers are
responsible for supplying catalogs. Concurrent access is synchronized with
locks; poisoned locks currently panic.
